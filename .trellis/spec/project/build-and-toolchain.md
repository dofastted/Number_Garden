# Build and Toolchain

> Evidence: `docs/TOOLCHAIN.md`, `build-profile.json5`, `hvigor/hvigor-config.json5`,
> `oh-package.json5`, `qa/logs/g0-assembleHap.log`.

## Pinned Versions

| Item | Value | Where |
|------|-------|-------|
| SDK | HarmonyOS 26.0.0 (API 26) | root `build-profile.json5` `targetSdkVersion` / `compatibleSdkVersion` = `"26.0.0"` |
| Model version | `26.0.0` | `hvigor/hvigor-config.json5` and root `oh-package.json5` (must be equal) |
| hvigor | 6.26.4 | bundled in command-line-tools |
| ohpm | 26.0.0.630 | bundled |
| Test framework | `@ohos/hypium` 1.0.29, `@ohos/hamock` 1.0.0 | root `oh-package.json5` `devDependencies` |

From API 26 the SDK version string is the bare platform version (`"26.0.0"`), not the older
`"x.y.z(API)"` form. Do not copy version strings from older projects or from memory; read them from the
installed SDK (`sdk/default/sdk-pkg.json`) and `docs/TOOLCHAIN.md`.

## Environment

```bash
export OHOS_CLT=/mnt/d/tools/harmonyos/cli-26.0.0.821/command-line-tools
export DEVECO_SDK_HOME=$OHOS_CLT/sdk
export PATH=$OHOS_CLT/bin:$OHOS_CLT/tool/node/bin:$OHOS_CLT/sdk/default/openharmony/toolchains:$PATH
```

Builds run in WSL against the repository on `/mnt/d`. Git runs through Windows `git.exe`
(`/mnt/c/Program Files/Git/cmd/git.exe`, `core.autocrlf=true`).

## Commands

| Purpose | Command (repo root) |
|---------|---------------------|
| Install deps | `ohpm install --all` |
| Debug HAP | `hvigorw assembleHap --mode module -p product=default -p buildMode=debug --no-daemon` |
| Lint | `codelinter` (uses `code-linter.json5`) |

Output: `entry/build/default/outputs/default/entry-default-unsigned.hap`. Save command output under
`qa/logs/` and reference it from `qa/STATUS.md`.

## API Lookup

Platform API declarations live in the installed SDK:

- `$DEVECO_SDK_HOME/default/openharmony/ets/api/` (e.g. `@ohos.data.relationalStore.d.ts`,
  `@ohos.data.preferences.d.ts`, `@ohos.taskpool.d.ts`)
- `$DEVECO_SDK_HOME/default/openharmony/ets/kits/` (`@kit.ArkData.d.ts`, `@kit.ArkUI.d.ts`, `@kit.ArkTS.d.ts`)
- `$DEVECO_SDK_HOME/default/hms/ets/api/` for HarmonyOS-only kits

Check signatures there before using an API. Do not use Java/Android APIs or FA-model APIs.

## Signing

`build-profile.json5` has an empty `signingConfigs`; builds are unsigned by design. Signing material
belongs to the user's AppGallery Connect account and is never committed or generated by an agent.

## Common Mistakes

- Changing `modelVersion` in only one of the two files.
- Committing `local.properties`, `oh_modules/` or build output.
- Reporting a build as passing without a saved log and exit code.
